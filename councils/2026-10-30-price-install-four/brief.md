# Brief: What to charge for install #4 onward

**The decision:** what price to quote for the content-ideas plugin done-for-you install from install #4 onward (December 2026), once the first 3 installs at $2,000 are done.

**Options**
- **A. Raise to $3,500** for the same done-for-you install plus 30 days of tuning.
- **B. Keep $2,000** (keep doing what I do now).
- **C. Keep $2,000 and add a $500 self-serve setup:** a guided install the client runs on their own Claude Code or Codex, with one 60-minute call and a written runbook.

**The business:** solo AI consultant, about $15k a month in consulting revenue (assumed). The offer is a fixed-scope install of the content-ideas plugin (a Claude Code and Codex plugin that scrapes competitors and produces a daily feed of content ideas) on the client's own API key, plus 30 days of tuning, sold to consultants and small agencies. A prior council set the plan: message 20 consultants by 2026-11-02, land 3 installs at $2,000 by 2026-11-30, and log install 1's hours by 2026-11-13. No install has been delivered yet, so hours per install are unknown (assumed 10 to 15 hours). Team: the founder alone, with AI agents.

**The resources:** about 10 founder hours a week for this (assumed); $5k cash set aside (assumed); decision needed by 2026-12-01 so December offers go out with the new price.

**What success looks like:** $5k a month in plugin-credited revenue by 2027-01-31 without cutting consulting hours (assumed, carried from the earlier council).

**The lean:** the founder leans toward **A**, because $2,000 for 10 to 15 hours plus 30 days of tuning pays less per hour than consulting, and a higher price filters for serious buyers (assumed). The worry: 3 installs is a thin signal, and a raise could stall sales before demand is proven.
