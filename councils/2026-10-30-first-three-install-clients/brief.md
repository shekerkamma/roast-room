# Brief: Which channel lands the first 3 install clients

**The decision:** which channel to use to land the first 3 paid clients for a $2,000 done-for-you install of the content-ideas plugin in the next 30 days.

**Options**
- **A. Daily LinkedIn content** about the plugin and its results.
- **B. Direct outreach** to 20 consultants in the founder's network.
- **C. Partner with 2 agency owners** on a 30% referral split ($600 per sale).
- **D. Wait and polish the product first** (keep doing what I do now).

**The business:** solo AI consultant, about $15k a month in consulting revenue. The new offer is a fixed-scope $2,000 install of the content-ideas plugin (a Claude Code and Codex plugin that scrapes competitors and produces a daily feed of content ideas) plus 30 days of tuning, sold to consultants and small agencies. No sales of the install yet. Team: the founder alone.

**The resources:** $5k set aside, about 10 hours a week for this, no email list, a network of consultants (size beyond the 20 named is unknown, assumed small). LinkedIn audience size unknown (assumed under 2,000 followers).

**What success looks like:** 3 paid installs ($6,000) by 2026-11-30.

**The lean:** B, because it is the fastest path to a yes.
